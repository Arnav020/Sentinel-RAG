# ==============================================================================
# INGESTION EXTRAS - pinned, layered on requirements-prod.txt
#
# These parse .docx/.pptx during ingestion only. app/ingestion/loaders/office.py
# imports them lazily, so the serving image stays free of them.
#
# This file used to install `unstructured`, which pulled spacy, thinc, blis,
# numba, llvmlite, langdetect and a dozen more packages into the ingest image to
# parse a handful of Office documents - and then flattened them to text with no
# heading or table structure, which is exactly what the chunker needs. Reading
# the formats directly is both smaller and better: Word heading styles and
# PowerPoint slide titles now become the chunk heading path.
